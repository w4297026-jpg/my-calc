Приношу извинения, теперь проблема полностью ясна. Ошибка «Ошибка загрузки данных» продолжает гореть, потому что бесплатный прокси-сервер api.allorigins.win, который мы добавили, столкнулся с ограничением на количество запросов в минуту или не успел вовремя передать файл. Чтобы калькулятор работал стабильно, мгновенно и без сторонних прокси-серверов, мы заменим тип запроса. Вместо скачивания файла таблицы в формате .csv, мы заставим скрипт обращаться к официальному API визуализации Google (/gviz/tq). Этот метод Google отдает без ограничений и блокировок по всему миру. Вот финальный и полностью автономный код. В нём переписан только блок получения данных — теперь он забирает информацию напрямую в чистом текстовом формате без сбоев.
